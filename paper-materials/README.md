## 推荐喂法（生成分享长图）

1. **最小配方**（生成高质量长图足够）：`00-核心数据速查.md` + `02-中文详读/06-主论文详读.md` + 下面的长图 Prompt
2. **进阶配方**（要讲项目实现）：再加 `05-项目文档/README-项目总览.md` + `04-演示页面/项目结构演示.html`
3. **要讲小模型矩阵**：再加 `02-中文详读/09-姊妹论文详读.md` + `05-项目文档/MODELS-小模型总盘点.md`

## 长图生成 Prompt（复制给 GPT，配合上面的文件）

```
你是一名资深信息图设计师兼前端工程师。我会给你几份关于论文
《The Attacker Moves Second》(USENIX Security 2026) 及其开源复现项目的材料，
请把其中内容做成一张「分享长图」：生成一个单文件 HTML（宽 1080px、
竖向滚动、无外部依赖、内联全部 CSS），我之后用浏览器整页截图导出 PNG。

【硬性规则】
1. 所有数字必须与我提供的材料完全一致，禁止改动或编造
2. 中文文字必须是可选中文本（不要用图片/Canvas 画文字），字号≥14px
3. 单文件、不引用任何外部资源；总高度 8000-12000px
4. 风格：科技感分享风，深蓝紫渐变(#0b1022→#1e1b4b)或明亮教学风任选；
   圆角卡片、emoji 图标、关键数字大号等宽字体、图表用纯 CSS 条形图

【内容结构】
1. 封面区：主标题+四个大数字卡（12个防御被击穿 / ASR推到90%+ /
   中位13-66次查询破防 / 单场景约$2）
2. 两类威胁对比：越狱 vs 提示注入（各配一个小例子）
3. 核心方法四步循环图：Propose→Score→Select(MAP-Elites)→Update
4. MAP-Elites 小图解：10×10网格+"按形态分组、每组留最强"
5. 战果条形图：12个防御 原ASR(灰条) vs 自适应后(红条)（数据见材料）
6. 破防实例：政策话术伪装/伪造前置流程/条件触发（材料里有原文）
7. 四条教训卡片
8. 我们的开源复现：Qwen3.8-27B@2×V100、246条真实种子、一键横评排行榜、
   实测"政策话术穿透DeBERTa"的发现
9. 页脚：仅用于自有系统安全评估 · 遵循论文伦理声明
```
